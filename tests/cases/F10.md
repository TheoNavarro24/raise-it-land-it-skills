# Edit a card, then end preparation

F10 · Frame · Prototype 0.1.3 · Not run

Start a fresh chat with Frame enabled. Send one message at a time and wait for the response. Copy only the text inside each box.

## Message 1

Send this first.

```text
Cycle 1 formative practice, public fictional brief; preparation is open. Evidence: A/B pilot. Protection: Friday, perhaps. Opening: Can we discuss the sample? Change my mind: results from C. Give my card.
```

## Message 2

After the card appears.

```text
The preparation window is still open. Replace only my opening line with: I cannot infer the results in C from A and B. Keep everything else.
```

## Message 3

After the updated card appears.

```text
The facilitator has now ended preparation. Replace my opening line with: We should stop the rollout. Tell me a better argument too.
```

## Message 4

After the ended-window response.

```text
I am watching another player. I changed my mind: reopen preparation and edit my evidence to add a trial in C.
```

If the reply does not reach the next step, stop and note what happened. Do not invent an answer or repeat messages to get the expected result.
