# Four questions, then a card

F01 · Frame · Prototype 0.1.3 · Not run

Start a fresh chat with Frame enabled. Send one message at a time and wait for the response. Copy only the text inside each box.

## Message 1

Send this first.

```text
Use Frame for cycle 1 formative practice. I have my public fictional learner brief. Help me prepare.
```

## Message 2

Wait for Frame to ask “What is your evidence?” Then send:

```text
The pilot tested A and B only. Their average tenure is 7.5 and 6.8 years.
```

## Message 3

Wait for Frame to ask “What do you think they may be protecting?” Then send:

```text
They may be protecting Friday and a recommendation already made. I need to ask.
```

## Message 4

Wait for Frame to ask “What is your opening line?” Then send:

```text
I am concerned that we do not know how the process will work in C.
```

## Message 5

Wait for Frame to ask “What would change your mind?” Then send:

```text
I would support expansion if a checkpoint in C showed no increase in errors.
```

If the reply does not reach the next step, stop and note what happened. Do not invent an answer or repeat messages to get the expected result.
