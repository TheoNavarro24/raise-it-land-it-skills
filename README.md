# Frame and Trace

Two prototypes for **Raise It, Land It**, my MDOE407 course-design project.

**Frame** helps a learner prepare for a difficult conversation. It asks four questions, then puts the learner's own answers into a preparation card.

**Trace** helps a tutor look back at a role-play. It points to what the learner actually said and identifies where the evidence is missing or unclear. The tutor still makes the assessment decision.

## Try them

1. [Download and install the skills](INSTALL.md).
2. Open [the Frame example](examples/frame-cycle1.md). It has five short messages to send, one at a time.
3. Open [the Trace example](examples/trace-demo.md). It has one conversation to copy into a new chat.

The examples are made up. You can use the supplied text or try your own fictional case. Once a skill is installed, you don't need to paste its instructions into the chat.

## Try the other test cases

[Browse all 33 tests](tests/README.md). Each has its own page with copyable messages and instructions on when to send them. The checks are on a separate page so you can review the response afterward.

You don't need to read JSON or write code to run these tests.

## Before you start

These are prototypes, not finished teaching tools. Frame is for the first practice round, not assessed preparation. Trace reviews a conversation after it has ended; it doesn't give grades or write a better answer for the learner.

They need an app that supports custom Agent Skills. A GitHub link lets you download the files; it doesn't open a ready-to-use chatbot in ChatGPT. [The installation guide](INSTALL.md) explains the available routes.

Earlier versions produced some successful ChatGPT responses and some loading failures. The current test pack hasn't been run across different models or in a recipient's account. [Testing notes](VALIDATION.md) explain what we know so far.
